# Curriculum

Тут зберігатимуться затверджені рішення щодо структури курсу.

Плановані файли:

- `blueprint.md` — повна карта модулів;
- `learning-outcomes.md` — результати навчання;
- `modules.yml` — машиночитна карта модулів і залежностей.

Рішення з `research/donors/` не переходять сюди автоматично: лише після нашої редакційної оцінки.
