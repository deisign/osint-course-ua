# Research layer

Цей каталог перетворює зовнішні курси, handbook-и, стандарти та кейси на контрольований набір «цеглин» для власного curriculum.

## Donor workflow

Для кожного джерела:

1. зафіксувати походження, автора, URL і дату перевірки;
2. розібрати структуру та навчальні результати;
3. виділити методологічні елементи;
4. позначити актуальність інструментальних частин;
5. перевірити ліцензійні обмеження;
6. зіставити з модулями нашого курсу;
7. присвоїти кожному елементу рішення:
   - `ADOPT` — беремо принцип майже без змін;
   - `ADAPT` — беремо і пристосовуємо;
   - `EXPAND` — беремо як основу та суттєво розширюємо;
   - `REBUILD` — зберігаємо навчальну мету, але матеріал створюємо заново;
   - `REJECT` — не використовуємо;
8. переносити затверджені рішення до `curriculum/`.

Аудит зовнішнього джерела не означає копіювання його текстів, вправ або матеріалів.
