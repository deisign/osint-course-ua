# OSINT Course UA

Робочий репозиторій україномовного курсу **«Професійний практик OSINT»**.

Мета курсу — навчати не набору інструментів, а відтворюваному циклу відкритого дослідження: постановка питання → план збору → пошук і збереження першоджерел → верифікація → аналіз альтернатив → оцінка впевненості → документування → peer review → публічний звіт або структурований пакет для передавання компетентним фахівцям.

Окремий обов’язковий контур присвячено Україні та Росії: регіональні джерела, військові формування, соціальні мережі й месенджери, відкриті реєстри, реконструкція інцидентів, документування ймовірних міжнародних злочинів та межі обґрунтованої атрибуції.

## Статус

**Pre-alpha / curriculum design.**

Наразі репозиторій містить концепцію курсу та дослідницький шар для системного розбору зовнішніх методологій, курсів і handbook-ів.

## Структура

- `docs/` — концепція, профіль випускника, карта компетентностей, термінологія.
- `curriculum/` — Curriculum Blueprint, навчальні результати, карта модулів.
- `research/donors/` — аудит зовнішніх курсів, handbook-ів і методологій.
- `research/sources/` — реєстр джерел і бібліографія.
- `standards/` — власний стандарт відкритого розслідування курсу.
- `modules/` — навчальні модулі.
- `labs/` — лабораторні роботи та еталонні рішення.
- `cases/` — сквозні навчальні кейси.
- `templates/` — робочі форми дослідника.
- `assessments/` — рубрики й оцінювання.
- `instructor/` — матеріали для викладача та перевіряльника.

## Принцип source of truth

Зміст курсу, рішення щодо структури та результати аудиту зовнішніх матеріалів фіксуються в цьому репозиторії. Чати, нотатки та експериментальні обговорення не вважаються остаточним джерелом істини, поки результат не перенесено сюди.

## Поточний виробничий порядок

1. Концепція курсу.
2. Профіль компетентностей випускника.
3. Curriculum Blueprint.
4. Термінологія.
5. OSINT Investigation Standard v0.1.
6. Пілотний модуль і лабораторна робота.
7. Внутрішній пілот.
8. Зовнішня експертна рецензія.

## Ліцензування

Власна ліцензія курсу ще не визначена. Зовнішні матеріали не копіюються автоматично: у `research/donors/` фіксуються методичні ідеї, посилання, статус ліцензії та рішення `ADOPT / ADAPT / EXPAND / REBUILD / REJECT`.
