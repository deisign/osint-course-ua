# L01 submission template

Create a copy of this directory for your submission.

## Required files

### `territory-map.md`

For each node include:

```text
ID:
Name / class:
Role:
Possible digital trace:
What it may support:
What it cannot establish alone:
Status: given | inferred | unknown
Connections:
- target ID — relationship — status — basis
```

### `source-ecosystem.csv`

Use the supplied CSV header and add rows.

### `collection-requirements.md`

Use repeated blocks:

```text
CR-ID:
Question:
Why it matters:
Potential sources:
Expected artefact:
Priority: high | medium | low
What result would support / contradict:
```

Minimum: 10 collection requirements.

### `gaps-and-alternatives.md`

For at least three important relationships:

```text
Relationship / claim:
Current status:
Primary interpretation:
Alternative explanation 1:
Alternative explanation 2:
What evidence would discriminate:
```

### `harm-note.md`

```text
Sensitive category:
Why collection/publication may create harm:
Is it necessary for the research question?:
Mitigation / data minimisation:
Stop / escalate condition:
```

## Rule

Do not add a relationship as `given` unless the input bundle explicitly provides it. A plausible system diagram is not the same as an evidenced system diagram.
