# L12 submission template

Create a copy of this directory for your submission.

## Required files

### `attribution-chain.md`

Assess each layer separately:

```text
Layer: account control | identity | affiliation | physical presence | specific action
Assessment:
Supporting observations:
Contradicting observations:
Unknowns:
Confidence:
```

### `indicator-matrix.csv`

Use the supplied CSV header and complete one row for each observation.

### `hypothesis-matrix.md`

Minimum hypotheses: H1–H4 from the task.

For each:

```text
Hypothesis:
Supporting observations:
Contradicting observations:
Non-discriminating observations:
Missing discriminating evidence:
Confidence:
```

### `claims-assessment.csv`

Use the supplied CSV header and assess all claims C1–C10.

### `final-conclusion.md`

Use these headings:

```text
## Established
## Plausible but not established
## Contradicted
## Unknown
## Viable alternatives
## Most discriminating next evidence
## Final confidence statement
```

### `peer-review-form.md`

Use `templates/peer-review-form.md` and explicitly flag any sentence where the conclusion exceeds the underlying evidence.

## Rule

Do not infer positive presence from missing location evidence. Do not infer account ownership from affiliation. Do not infer action from presence or account control.
